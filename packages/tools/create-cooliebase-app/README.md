# create-cooliebase-app

Zero-Git-History instant scaffolding CLI for **cooliebase-all** enterprise Next.js fullstack foundation.

## 🚀 极速起步 (Quick Start)

### 交互式创建
```bash
npx create-cooliebase-app
# 或
pnpm create cooliebase-app
```

### 单行静默创建 (适合 AI Agent 与 CI 自动化)
```bash
npx create-cooliebase-app my-app --title "XX智慧管理平台" --profile base --port 3300
```

## 📐 规格 Profile 说明
- `base`: 极纯净核心底座（仅含 shared + system RBAC + infra 基础设施，轻量秒编译）；
- `minimal`: 底座 + 在线低代码与大模型网关；
- `standard`: 全量 17 业务域与跨端 Expo 移动客户端。
