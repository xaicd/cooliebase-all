# CoolieBase All `v1.5.0` Release Notes

- **发布版本 (Tag)**: `v1.5.0`
- **模板基线 (`templateVersion`)**: `1.5.0`
- **发布日期**: 2026-11-16
- **架构定位**: 企业级四位一体轻全栈可派生旗舰底座（Next.js 16 + React 19 + Prisma 7 + Kysely + Expo App + Uni-App MiniApp）

---

## 核心里程碑亮点

### 1. 四位一体多端拓扑齐备 (`Admin + 2C Portal + Expo App + MiniApp`)
- **新增 `clients/miniapp/`（微信小程序 + H5 多端客户端）**：
  - 基于 **Uni-App Vue 3 + TypeScript + Vite** 构建，零第三方冗余品牌残留，零新增供应链漏洞债务；
  - `clients/miniapp/src/utils/request.ts` 内置动态 `VITE_API_BASE_URL` / `BASE_PATH`（`/${slug}/api/v1/app`）解析、`X-Client-Channel: miniapp` 标准头、Bearer Token 自动注入、单飞刷新与 `wx.login` (`wxSilentLogin`) 静默授权闭环；
  - 配备 4 大极简短词 TabBar 页面（`首页`、`分类`、`工作台`、`我的`）、`subPackages` 分包配置及 iPhone `env(safe-area-inset-bottom)` 安全区适配；
  - 全链路接入 `scripts/project-init.cjs` / `scripts/clone-project-base.cjs` 白标孵化引擎、`packages/shared/contract/client-channels.json` 与 `scripts/check-client-build.cjs` 无污染构建门禁。

### 2. 20 大原生企业域齐备与边界净化（2 平台地基 + 18 第一方插件，`+oa/hrm/fms/pms`）
- **新增 4 大政企核心第一方业务插件**（全部由 `<500 Tokens` 表元数据经 `CodegenEngineService` 全栈展开，自动生成幂等迁移、仓储、服务、Zod 校验器、Domain Facade、前端管理页与机器可读 `*.agent.json` 契约）：
  - **`oa`（协同办公，端口 `3226`）**：`OaNotice` 通知公告、`OaAttendance` 考勤打卡、`OaLeaveApply` 请假用印；
  - **`hrm`（人力资源，端口 `3227`）**：`HrmEmployee` 员工档案、`HrmPosition` 岗位编制、`HrmPayroll` 薪资核算；
  - **`fms`（财务管理，端口 `3228`）**：`FmsAccount` 资金账户、`FmsVoucher` 收支凭证、`FmsReconcile` 对账结算（金额列全量遵循 `decimal` 定点精度纪律）；
  - **`pms`（项目管理，端口 `3229`）**：`PmsProject` 项目台账、`PmsMilestone` 里程碑、`PmsTimesheet` 任务工时。
- **彻底剥离非原生垂直定制插件**：
  - `plugin-ai` 开放接口内聚自闭环，物理清理历史垂直定制插件目录，`check-engineering-standards.cjs` 中 `KNOWN_CUSTOM` 历史豁免与全部架构棘轮基线残留 100% 清零；
  - 全仓收敛为 **20 个标准原生域**（2 个平台地基 `system/infra` + **18 个第一方插件**，含 `online` 低代码域与 17 个企业业务插件）及 **354 份机器可读 Agent 契约**。

### 3. 跨底座 CLI 与 23 道出厂门禁 100% 同名同参对齐 (`vs yudao-quad-terminal`)
- 新增并全量接入 `pnpm harness` 可达性治理的跨底座标准入口：
  - `pnpm run project:reactor`（白标原地重构与沙箱克隆派生）
  - `pnpm run gates:23` / `pnpm run gates:23:static`（`scripts/audit-23-gates.cjs` 统一出厂硬门禁审计）
  - `pnpm run gen:three-role`（`scripts/scaffold-three-role-audit.cjs` 生成/核验 FDA + FDSE + DS 三角色审计单与 PostgreSQL Append-Only SHA-256 链式防篡改审计触发器）
  - `pnpm run domain:prune` / `pnpm run trim:modules` / `pnpm run trim:check`（`scripts/domain-prune.cjs` 第一方插件按需裁剪与一致性核验）
  - `pnpm run gateway:gen`（渲染四端统一反向代理 Caddy 配置）
  - `pnpm run verify:b0` ~ `pnpm run verify:b5`（分阶段标准化验收矩阵）
  - `pnpm run dev:miniapp` / `build:miniapp` / `dev:app` / `build:admin`（四端标准开发与构建别名）
